## 📖 Overview

**Suroy** (Cebuano for "to wander" or "go around") is a cross-platform mobile application designed to revolutionize the local tourism industry. It solves two major travel hurdles: **planning complex itineraries** and **managing travel costs**.

By combining modern mobile architecture with advanced NLP, Suroy creates personalized travel experiences while connecting solo travelers to share expenses.

## ⚙️ Technical Highlights: Vector Embeddings & NLP

Unlike standard keyword search, Suroy utilizes **Vector Embeddings** to power its AI engine. 

* **How it works:** User preferences and travel descriptions are converted into high-dimensional vectors.
* **The Result:** This allows the application to perform **semantic search** and matching. If a user asks for a "peaceful escape near the ocean," the NLP engine understands the context and matches them with itineraries tagged with "serene," "beach," or "coastal," even if the exact keywords don't match.
* **Efficiency:** Optimized for mobile execution to ensure fast retrieval of matching itineraries.

## ✨ Key Features

* **🤖 AI-Generated Itineraries:** Instantly creates travel plans based on budget, duration, and mood using NLP.
* **🤝 Traveler Matching:** A "Tinder-like" system for finding travel buddies to split costs on transport and accommodation.
* **📱 Cross-Platform:** Built with React Native for a seamless experience on both iOS and Android.
* **🗺️ Smart Tourism:** Focuses on highlighting local spots in Cebu and Central Visayas.

## 🚀 Tech Stack

* **Frontend:** React Native
* **AI & Backend:** Python, Natural Language Processing (NLP)
* **Data:** Vector Database / Embeddings
* **Integration:** REST APIs

## 🛠️ Installation

1.  **Clone the repo**
    ```bash
    git clone https://github.com/llegaspo/Suroy.git
    ```
2.  **Install dependencies**
    ```bash
    npm install
    ```
3.  **Run on Simulator/Device**
    ```bash
    npx react-native run-android
    # or
    npx react-native run-ios
    ```
